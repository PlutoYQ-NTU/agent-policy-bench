# Security Policy

`agent-policy-bench` does not execute shell commands. It reads a command corpus and prediction file, then writes a local report.

Do not add real credentials, private keys, tokens, cookies, private repository paths, or sensitive logs to corpora, prediction fixtures, examples, or reports.

The benchmark is a scoring aid, not a security boundary. Passing this benchmark does not prove that an approval policy is safe, complete, or production-ready.
